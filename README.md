- **Prize pool:** $2 winner-take-all

- **Harness:** program/v1

## The line

> Your mother won't always be a phone call away — call her while she still answers.

- **Character count:** 81 (max 200)
- **SHA-256:** `75e7d6dee59bdfcee6226584f47fb6891a74ae9bb7e1690eb0aea0748872ad45`
- **Trailing newline:** none — the output file is byte-identical to the line above.

## Run

Requires Python 3. By default, the program creates `/output` if needed and writes `/output/entry.txt`.

```sh
python3 main.py
```

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

The program only creates the output directory if it does not exist and writes `entry.txt` inside it. It never deletes anything and never writes into the repo.
